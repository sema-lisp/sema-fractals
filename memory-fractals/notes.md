# Address-dependent recursive experiments

Generated geometry with Sema 1.37.0. Pillow rasterizes the Sema geometry with antialiasing and a faint glow. Colours use Splash's charcoal, yellow, cyan, and lilac tokens.

These are custom constructions created for this experiment. Mathematical priority, Hausdorff dimension, and equivalence to known systems have not been established. Finite renderings approximate infinite recursive constructions.

## Address Lace

Each node has five children. The inherited phase changes according to `m' = 0.71*m + 0.93*k + 0.31*sin(2*m)`. Child scale is `0.285 + 0.025*cos(m')`, so it lies between 0.26 and 0.31. Phase changes the orientation of subsequent five-port motifs. Circular outlines and links reveal the genealogy.

## Signed Braid

Three curved descendants carry signed memory. `m' = s_k*0.63*m + k - 1 + 0.27`, with the middle branch reversing the memory sign. Scale lies between 0.405 and 0.455. Inherited memory changes local curvature and orientation. Each generation contains three smaller curved motifs.

## Phase Coral

Seven initial arms each produce four descendants. `m' = 0.81*m + 1.17*(k-1.5) + 0.25*sin(m)`. Memory changes stem curvature and branch spread. Length ratios lie between 0.435 and 0.505. Each arm therefore has a bounded total path length.
